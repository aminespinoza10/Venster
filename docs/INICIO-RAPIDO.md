# 🚀 Inicio Rápido - Venster

## Despliegue en 3 pasos

### 1️⃣ Clonar el repositorio
```bash
git clone https://github.com/aminespinoza10/Venster.git
cd Venster
```

### 2️⃣ Configurar (opcional)
```bash
# Si quieres personalizar la URL de Ollama
cp .env.docker .env
# Edita .env según tus necesidades
```

### 3️⃣ Arrancar todo
```bash
./deploy.sh
```

Selecciona la opción **1** del menú.

## 🌐 Acceder

- **Web**: http://localhost
- **API**: http://localhost:8080
- **Swagger**: http://localhost:8080/swagger/

## 🛑 Detener

```bash
./deploy.sh
```

Selecciona la opción **4** del menú.
